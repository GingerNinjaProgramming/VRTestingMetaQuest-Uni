# VRTestingMetaQuest-Uni

## Game Breakdown 

Our game was a VR recreation/reimagining of the classic NES game Duck Hunt, my task specifically was to implement sound effects and a menu to the game to give the player audio feedback on shooting ducks and the dog laughing at the end of the round, as well as give the player the ability to change a variety of settings within the game such as lighting and graphics quality. Initially I considered using a sound pack I had found on itch.io that would work for gunshots but eventually settled on sourcing sound effects from jsfxr which is a website that allows you to generate 8-bit or retro sound effects as I felt that these more appropriately fit the general theme of the game being retro stylised. I used metasounds in order to add some slight pitch variance between subsequent shots of the gun and shots of the ducks. The menu was also fairly simple to make simply adapting a task I had done before with adjusting scalability to work better within a VR setting.
